# Application mobile (responsable : développeur mobile)

Créer **ici** l'application React Native / Expo Go lors de la prochaine étape.

Écrans V1 recommandés :
- Tableau de bord (LED 1, LED 2, connexion ESP32).
- Contrôle détaillé des LED (ON/OFF, couleur, intensité).
- Scénarios (Lecture, Cinéma, Nuit, scénarios personnalisés locaux).
- Luminosité et alertes (mesure, seuil, notification dans l'interface).

Ne pas mettre d'identifiants AWS permanents dans l'application. L'endpoint AWS est une configuration publique, mais les clés et tokens privés ne doivent jamais être intégrés dans le dépôt.

Commencer l'interface avec des données simulées ; substituer ensuite un service MQTT conforme au contrat.
